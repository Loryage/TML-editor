# TML Markdown Editor v2.0

   一个轻量但功能完整的桌面编辑器，专为 Markdown 写作而生。提供自动分屏预览、多标签管理、悬停放大与滚动同步，适合在拥挤桌面写作、快速记录与排版。支持安卓端，现已支持多端同步文档(处于测试中)。
   
   软件已打包为安装程序，安装即用，源码已整理为main.py。以下为演示视频（有概率加载失败变为空白）：

![视频演示](assets/show.gif)

## 亮点特性
- 多端同步：安卓端与电脑端可同步文件，实现编辑自由。
- 悬停放大：鼠标进入任意一侧，自动放大阅读或编辑区域。
- 窗口小巧：不挡桌面，加上智能分屏信息密度高，参考和修改更方便。
- 智能分屏：Markdown 文件自动启用分屏，非 Markdown 自动关闭。
- 快速打开：将文档拖动到程序上方即可自动解析和打开。
- 多格式支持：.md / .txt / .tex / .py 等文本文件，自动识别多种编码格式。
- 实时预览：左侧预览、右侧编辑，渲染即时刷新。
- 多标签页：同时编辑多个文档，关闭前自动提示未保存。
- 滚动同步：预览区与编辑区按百分比同步滚动。
- 语法高亮：标题、粗体、斜体、行内代码、链接。
- 预览样式：默认内置排版样式，覆盖标题、代码块、引用与表格。

## 使用方式

- 文件菜单：新建、打开、保存、另存为。
- 视图菜单：预览缩放、分屏模式切换。
- 同步菜单：同步设置、完成设置后即可同步。
- 帮助菜单：查看使用指导。

## 功能一览

- 分屏预览模式：左侧只读预览，右侧源码编辑。
- 自动分屏切换：基于文件扩展名自动判断。
- 预览缩放：支持放大/缩小预览字体。
- 状态栏提示：显示当前文件与保存及同步状态。

## 适用场景

- 轻量文稿整理与导出
- 跨平台文档编辑、同步
- Markdown 轻写作与排版
- 技术文档草拟与预览
